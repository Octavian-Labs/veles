# ВЕЛЕС — русская экосистема программирования

Собственная система программирования «с нуля»: три языка, образующие линию
восхождения от машинного кода к сознанию:

| Язык | Уровень | Статус |
|------|---------|--------|
| **ИСКРА** | ассемблер x86-64 | ✅ работает: PE64/ELF64, настоящий машинный код, самохост (`иск/`) |
| **РАЗУМ** | системный (C-уровень) | ✅ самохост (`raz/`): методы, срезы, модули, stdlib, оптимизатор |
| **ЯР** | флагман (динамический) | 📐 спека 2.0 (EBNF) готова |

РАЗУМ компилируется в текст ИСКРЫ, а ИСКРА производит настоящий машинный
код x86-64 и исполняемые файлы Windows (PE64) и Linux (ELF64) — без
виртуальных машин и интерпретаторов.

```
программа.раз → разум.exe → программа.иск → искра.exe → программа.exe
```

## Быстрый старт

```powershell
# РАЗУМ: компилируем и запускаем «Привет, мир!»
raz\разум.exe < examples\привет.раз > привет.иск
искра.exe < привет.иск > привет.exe
.\привет.exe              # → Привет, мир!

# ИСКРА напрямую — тот же пример на ассемблере
искра.exe < examples\привет.иск > привет_иск.exe

# Уровни оптимизации: -O0 (без оптимизаций) / -O1 (по умолчанию)
raz\разум.exe -O0 < examples\привет.раз > привет_o0.иск
```

`разум.exe` читает исходник со stdin и пишет текст ИСКРЫ на stdout;
`искра.exe` читает `.иск` со stdin и пишет исполняемый файл на stdout.
Модули `взять` ищутся в текущем каталоге и в `../lib/`.

Пример на РАЗУМЕ (`examples/привет.раз`):

```go
внеш "kernel32" функ GetStdHandle(деск без32) без64
внеш "kernel32" функ WriteFile(хендл без64, буф *без8,
                               колво без32, записано *без32, овер *пусто) цел32

функ главная():
    сооб := "Привет, мир!\r\n"
    записано без32 = 0
    х := GetStdHandle(0xFFFFFFF5)
    WriteFile(х, сооб.данные, сооб.длина как без32, &записано, пусто)
    верни 0
```

Пример исходника (`examples/привет.иск`):

```asm
ИМПОРТ "kernel32.dll" GetStdHandle, WriteFile, ExitProcess

СЕКЦИЯ данные
сообщение:  БАЙТ "Привет, мир!", 13, 10
длина       РАВНО $ - сообщение
записано:   ДВСЛОВО 0

СЕКЦИЯ код
ВХОД старт
старт:
    ВЫЧ УКС, 40              ; теневое пространство + выравнивание
    ПЕР СЧТМ, -11            ; STD_OUTPUT_HANDLE
    ВЫЗОВ GetStdHandle
    ПЕР СЧТ, АКК
    АДР ДАН, [сообщение]
    ПЕР Р8М, длина
    АДР Р9, [записано]
    ПЕР КВАД [УКС+32], 0
    ВЫЗОВ WriteFile
    ИИЛИ СЧТМ, СЧТМ
    ВЫЗОВ ExitProcess
```
