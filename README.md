# РЯП — русский язык программирования

Собственная система программирования «с нуля»: **русский ассемблер РАСМ**,
генерирующий настоящий машинный код x86-64 и исполняемые файлы
Windows (PE64) и Linux (ELF64). Далее по плану — русские C-подобный
(«СИ-РУС») и C++-подобный («СИ++-РУС») языки.

## Быстрый старт

```powershell
# «Привет, мир!» под Windows — собрать и запустить
cd src
python -m asm_rus ..\examples\привет.асм -o ..\examples\привет.exe
..\examples\привет.exe        # → Привет, мир!

# Тот же язык под Linux (ELF64)
python -m asm_rus ..\examples\привет_linux.асм --цель linux -o ..\examples\привет
```

Пример исходника (`examples/привет.асм`):

```asm
ИМПОРТ "kernel32.dll" GetStdHandle, WriteFile, ExitProcess

СЕКЦИЯ данные
сообщение:  БАЙТ "Привет, мир!", 13, 10
длина       РАВНО $ - сообщение
записано:   ДВСЛОВО 0

СЕКЦИЯ код
ВХОД старт
старт:
    ВЫЧ УКС, 40              ; теневое пространство + выравнивание
    ПЕР СЧТМ, -11            ; STD_OUTPUT_HANDLE
    ВЫЗОВ GetStdHandle
    ПЕР СЧТ, АКК
    АДР ДАН, [сообщение]
    ПЕР Р8М, длина
    АДР Р9, [записано]
    ПЕР КВАД [УКС+32], 0
    ВЫЗОВ WriteFile
    ИИЛИ СЧТМ, СЧТМ
    ВЫЗОВ ExitProcess
```
