# ВЕЛЕС

**ВЕЛЕС** — русскоязычная кроссплатформенная экосистема программирования: от настоящих машинных инструкций до системных и прикладных языков.

```text
ИСКРА  →  РАЗУМ  →  ЯР
x86-64    системы    высокий уровень
```

Проект создаётся с нуля и нацелен на прозрачную цепочку:

```text
исходный код → AST → ИСКРА → машинные байты → PE64 / ELF64
```

## Состав проекта

### ИСКРА

Русскоязычный ассемблер x86-64. ИСКРА кодирует настоящие машинные инструкции и умеет формировать исполняемые файлы для Windows PE64 и Linux ELF64.

Возможности:

- русские мнемоники с поддержкой английских имён регистров;
- x86-64 и адресация Intel-подобного вида;
- метки, константы, выражения и секции;
- данные, выравнивание и резервирование памяти;
- Windows DLL imports;
- Linux `syscall`;
- генерация PE64 и ELF64;
- родной CLI: `искра < файл.иск > файл.exe`.

### РАЗУМ

Статически типизированный системный язык, компилируемый в ИСКРУ.

Основные идеи:

- ручное управление памятью;
- отсутствие обязательного GC;
- указатели, массивы и срезы;
- функции и методы;
- модули;
- внешние функции и вставки `искра:`;
- строки `{данные, длина}`;
- платформенные модули стандартной библиотеки;
- стековый кодогенератор с последующим развитием оптимизаторов.

### ЯР

Будущий язык верхнего уровня экосистемы ВЕЛЕС. Его цель — код, который читается как русская речь: динамическая типизация, отступы-блоки, интерполяция строк и удобная стандартная библиотека.

ЯР находится на стадии проектирования и спецификации.

## Быстрый старт

Никаких внешних зависимостей: ВЕЛЕС самодостаточен, toolchain собран
и лежит в репозитории. Компилятор РАЗУМ написан на РАЗУМЕ и собирает
сам себя.

```bash
git clone https://github.com/Octavian-Labs/veles.git
cd veles
```

Windows:

```powershell
raz\разум.exe < examples\вычисления.раз > вычисления.иск
.\искра.exe < вычисления.иск > вычисления.exe
.\вычисления.exe            # код выхода 55
```

Linux:

```bash
./raz/разум --цель linux < examples/выход_linux.раз > выход.иск
./искра < выход.иск > выход
chmod +x выход && ./выход   # код выхода 42
```

`разум` читает исходник со stdin и пишет ИСКРУ в stdout; флаги
`--цель linux` и `--цель macos` включают SysV ABI и прагму `;цель`
в выводе. `искра` читает ИСКРУ со stdin и пишет готовый исполняемый
файл — PE64, ELF64 или Mach-O (x86-64) по прагме `;цель` в первой
строке исходника.

macOS (x86-64, на Apple Silicon — через Rosetta 2):

```bash
./raz/разум --цель macos < examples/выход_linux.раз > выход.иск
./искра < выход.иск > выход
chmod +x выход && ./выход   # код выхода 42
```

## Примеры ИСКРЫ

Сборка Linux ELF64:

```bash
./искра < examples/привет_linux.иск > привет
chmod +x привет
./привет
```

Сборка Windows PE64:

```powershell
.\искра.exe < examples\привет.иск > привет.exe
.\привет.exe
```

Минимальная программа на ИСКРЕ:

```asm
СЕКЦИЯ код
ВХОД старт

старт:
    ВЫЧ УКС, 8
    ПЕР АКК, 0
    ВЫЗОВ ExitProcess

СЕКЦИЯ данные
```

## Поддерживаемые цели

| Компонент | Windows x64 | Linux x64 | macOS x64 | ARM64 |
|---|---:|---:|---:|---:|
| ИСКРА: кодировщик x86-64 | работает | работает | работает | в планах |
| PE64 | работает | — | — | — |
| ELF64 | — | работает | — | — |
| Mach-O | — | — | работает | — |
| РАЗУМ | работает | работает | работает | в планах |
| ЯР | спецификация | спецификация | спецификация | спецификация |

Переносимость означает сборку исходного текста под конкретную цель. Один бинарник PE64 не запускается на Linux, а ELF64 не запускается на Windows без совместимого слоя.

Дальнейшие цели — по [ROADMAP.md](ROADMAP.md): пара «система-машина»
(`uefi-x86_64`, `голо-x86_64`, затем `*-а64` и `*-рв64`), кодеры
ИСКРЫ как сменные модули.

## Архитектура

```text
иск/                # ассемблер ИСКРА на РАЗУМЕ (самохост)
  кодер.раз         # кодирование x86-64
  пе.раз            # генерация PE64
  эльф.раз          # генерация ELF64
  махо.раз          # генерация Mach-O (x86-64)
raz/                # компилятор РАЗУМ на РАЗУМЕ (самохост)
  ген.раз           # генерация ИСКРЫ (регистровые локали, пипхол)
  опт.раз           # пипхол-оптимизатор
биб/                # стандартная библиотека на РАЗУМЕ (windows/linux/macos)
тесты/              # нативный тест-раннер + кейсы
след/               # машинный отладчик СЛЕД (Win32 Debug API)
examples/           # примеры .раз и .иск + бенчмарки
docs/               # документация
.github/workflows/  # CI: нативный прогон тестов + фикс-поинт
```

Сиды toolchain закоммичены в репозитории: `искра.exe`, `искра`,
`raz/разум.exe`, `raz/разум`. Ими же и пересобираются: компилятор
компилирует свой исходник, и фикс-поинт (два поколения выдают
идентичную ИСКРУ побайтно) проверяется в CI на обеих ОС.

## Развитие без наслоений

ВЕЛЕС рассчитан на долгую жизнь без устаревших слоёв (канон §11–14):

- устаревшее уходит по конвейеру «предупреждение → ошибка → удаление»,
  миграцию исходников делает инструмент `переведи` — компилятор
  старость не носит;
- цель — пара система-машина, текст ИСКРЫ — единый IR РАЗУМА:
  новая архитектура = новый кодер, а не новый язык;
- память делится на домены (процесс/прибор/стойкая/дальняя) —
  задел под ускорители и разные типы памяти;
- параллелизм строится на атомах и оградах канона, а не на
  соглашениях «как получится».

## Тесты и разработка

Нативный тест-раннер — `тесты/прогон.раз`: компилирует примеры и кейсы
цепочкой разум→искра, запускает результаты и сверяет коды выхода и вывод.
Запуск из корня репозитория:

```powershell
raz\разум.exe < тесты\прогон.раз > прогон.иск
.\искра.exe < прогон.иск > прогон.exe
.\прогон.exe
```

```bash
./raz/разум --цель linux < тесты/прогон.раз > прогон.иск
./искра < прогон.иск > прогон
chmod +x прогон && ./прогон
```

Изменения вносятся через feature-ветки от `develop`, PR и зелёный CI.
