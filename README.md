# ВЕЛЕС — русская экосистема программирования

Собственная система программирования «с нуля»: три языка, образующие линию
восхождения от машинного кода к сознанию:

| Язык | Уровень | Статус |
|------|---------|--------|
| **ИСКРА** | ассемблер x86-64 | ✅ работает: PE64/ELF64, настоящий машинный код |
| **РАЗУМ** | системный (C-уровень) | ✅ v0.2: методы, литералы, срезы, модули, искра-локали |
| **ЯР** | флагман (динамический) | 📐 спека 2.0 (EBNF) готова |

РАЗУМ компилируется в текст ИСКРЫ, а ИСКРА производит настоящий машинный
код x86-64 и исполняемые файлы Windows (PE64) и Linux (ELF64) — без
виртуальных машин и интерпретаторов.

## Быстрый старт

```powershell
# РАЗУМ: компилируем и запускаем «Привет, мир!»
cd src
python -m razum ..\examples\привет.раз -o ..\examples\привет.exe
..\examples\привет.exe        # → Привет, мир!

# ИСКРА напрямую — тот же пример на ассемблере
python -m iskra ..\examples\привет.иск -o ..\examples\привет_иск.exe

# Linux-цель (ELF64)
python -m razum ..\examples\выход_linux.раз --цель linux -o ..\выход
```

Пример на РАЗУМЕ (`examples/привет.раз`):

```go
внеш "kernel32" функ GetStdHandle(деск без32) без64
внеш "kernel32" функ WriteFile(хендл без64, буф *без8,
                               колво без32, записано *без32, овер *пусто) цел32

функ главная():
    сооб := "Привет, мир!\r\n"
    записано без32 = 0
    х := GetStdHandle(0xFFFFFFF5)
    WriteFile(х, сооб.данные, сооб.длина как без32, &записано, пусто)
    верни 0
```

Пример исходника (`examples/привет.иск`):

```asm
ИМПОРТ "kernel32.dll" GetStdHandle, WriteFile, ExitProcess

СЕКЦИЯ данные
сообщение:  БАЙТ "Привет, мир!", 13, 10
длина       РАВНО $ - сообщение
записано:   ДВСЛОВО 0

СЕКЦИЯ код
ВХОД старт
старт:
    ВЫЧ УКС, 40              ; теневое пространство + выравнивание
    ПЕР СЧТМ, -11            ; STD_OUTPUT_HANDLE
    ВЫЗОВ GetStdHandle
    ПЕР СЧТ, АКК
    АДР ДАН, [сообщение]
    ПЕР Р8М, длина
    АДР Р9, [записано]
    ПЕР КВАД [УКС+32], 0
    ВЫЗОВ WriteFile
    ИИЛИ СЧТМ, СЧТМ
    ВЫЗОВ ExitProcess
```
