# ВЕЛЕС — русская экосистема программирования

Собственная система программирования «с нуля»: три языка, образующие линию
восхождения от машинного кода к сознанию:

| Язык | Уровень | Назначение |
|------|---------|-----------|
| **ИСКРА** | ассемблер x86-64 | первый разряд — голый процессор, PE64/ELF64 |
| **РАЗУМ** | системный (C-уровень) | ядра, драйверы, рантаймы — *в планах* |
| **ЯР** | флагман (динамический) | «код как речь»: ОС, ИИ-системы, нейро-платформы — *спека готова* |

ИСКРА генерирует настоящий машинный код x86-64 и исполняемые файлы
Windows (PE64) и Linux (ELF64) — без виртуальных машин и интерпретаторов.

## Быстрый старт

```powershell
# «Привет, мир!» под Windows — собрать и запустить
cd src
python -m iskra ..\examples\привет.иск -o ..\examples\привет.exe
..\examples\привет.exe        # → Привет, мир!

# Тот же язык под Linux (ELF64)
python -m iskra ..\examples\привет_linux.иск --цель linux -o ..\examples\привет
```

Пример исходника (`examples/привет.иск`):

```asm
ИМПОРТ "kernel32.dll" GetStdHandle, WriteFile, ExitProcess

СЕКЦИЯ данные
сообщение:  БАЙТ "Привет, мир!", 13, 10
длина       РАВНО $ - сообщение
записано:   ДВСЛОВО 0

СЕКЦИЯ код
ВХОД старт
старт:
    ВЫЧ УКС, 40              ; теневое пространство + выравнивание
    ПЕР СЧТМ, -11            ; STD_OUTPUT_HANDLE
    ВЫЗОВ GetStdHandle
    ПЕР СЧТ, АКК
    АДР ДАН, [сообщение]
    ПЕР Р8М, длина
    АДР Р9, [записано]
    ПЕР КВАД [УКС+32], 0
    ВЫЗОВ WriteFile
    ИИЛИ СЧТМ, СЧТМ
    ВЫЗОВ ExitProcess
```
