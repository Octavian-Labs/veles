# ВЕЛЕС

**ВЕЛЕС** — русскоязычная кроссплатформенная экосистема программирования: от настоящих машинных инструкций до системных и прикладных языков.

```text
ИСКРА  →  РАЗУМ  →  ЯР
x86-64    системы    высокий уровень
```

Проект создаётся с нуля и нацелен на прозрачную цепочку:

```text
исходный код → AST → ИСКРА → машинные байты → PE64 / ELF64
```

## Состав проекта

### ИСКРА

Русскоязычный ассемблер x86-64. ИСКРА кодирует настоящие машинные инструкции и умеет формировать исполняемые файлы для Windows PE64 и Linux ELF64.

Возможности:

- русские мнемоники с поддержкой английских имён регистров;
- x86-64 и адресация Intel-подобного вида;
- метки, константы, выражения и секции;
- данные, выравнивание и резервирование памяти;
- Windows DLL imports;
- Linux `syscall`;
- генерация PE64 и ELF64;
- CLI и Python API.

### РАЗУМ

Статически типизированный системный язык, компилируемый в ИСКРУ.

Основные идеи:

- ручное управление памятью;
- отсутствие обязательного GC;
- указатели, массивы и срезы;
- функции и методы;
- модули;
- внешние функции и вставки `искра:`;
- строки `{данные, длина}`;
- платформенные модули стандартной библиотеки;
- стековый кодогенератор с последующим развитием оптимизаторов.

### ЯР

Будущий язык верхнего уровня экосистемы ВЕЛЕС. Его цель — код, который читается как русская речь: динамическая типизация, отступы-блоки, интерполяция строк и удобная стандартная библиотека.

ЯР находится на стадии проектирования и спецификации.

## Быстрый старт

Требуется Python 3.11+.

```bash
git clone https://github.com/Octavian-Labs/veles.git
cd veles
python -m venv .venv
```

Linux/macOS:

```bash
source .venv/bin/activate
python -m pip install -e .
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
```

Проверка проекта:

```bash
python -m pytest
```

## Примеры ИСКРЫ

Сборка Linux ELF64:

```bash
python -m iskra examples/привет_linux.иск --цель linux -o привет
chmod +x привет
./привет
```

Сборка Windows PE64:

```powershell
python -m iskra examples/привет.иск -o привет.exe
.\привет.exe
```

Минимальная программа на ИСКРЕ:

```asm
СЕКЦИЯ код
ВХОД старт

старт:
    ВЫЧ УКС, 8
    ПЕР АКК, 0
    ВЫЗОВ ExitProcess

СЕКЦИЯ данные
```

## Поддерживаемые цели

| Компонент | Windows x64 | Linux x64 | macOS | ARM64 |
|---|---:|---:|---:|---:|
| ИСКРА: кодировщик x86-64 | работает | работает | в планах | в планах |
| PE64 | работает | — | — | — |
| ELF64 | — | работает | — | — |
| РАЗУМ | работает | работает | в планах | в планах |
| ЯР | спецификация | спецификация | спецификация | спецификация |

Переносимость означает сборку исходного текста под конкретную цель. Один бинарник PE64 не запускается на Linux, а ELF64 не запускается на Windows без совместимого слоя.

## Архитектура

```text
src/iskra/
  lexer.py       лексический анализ
  expr.py        выражения и метки
  parser.py      разбор операторов и операндов
  regs.py        русские псевдонимы регистров
  encoder.py     кодирование x86-64
  assembler.py   двухпроходная сборка
  emit_pe.py     генерация PE64
  emit_elf.py    генерация ELF64

src/razum/
  lexer.py       лексический анализ
  parser.py      синтаксический анализ
  nodes.py       AST-узлы
  gen.py         генерация ИСКРЫ
  loader.py      загрузка модулей
```

## Статус

ВЕЛЕС находится в активной разработке. ИСКРА уже собирает нативный код x86-64 для PE64 и ELF64, а РАЗУМ компилируется в ИСКРУ. API, синтаксис и формат стандартной библиотеки пока могут изменяться.

Приоритеты развития:

1. оптимизация генерируемого кода;
2. расширение стандартной библиотеки;
3. интеграционные тесты сборки и запуска;
4. самораскрутка компилятора РАЗУМА;
5. macOS Mach-O и ARM64;
6. реализация ЯРА.
