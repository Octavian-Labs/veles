# Course — проектный курс по РАЗУМУ

Интерактивный веб-учебник: вместо «теория → примеры» вы **сразу пишете
настоящую программу** — интерактивную текстовую викторину — и изучаете
язык по мере того, как конструкции понадобились в коде.

## Запуск

Откройте `index.html` в браузере — достаточно двойного щелчка.
Либо через локальный сервер (необязательно):

```powershell
Set-Location Course; python -m http.server 8000
# затем http://localhost:8000
```

## Как устроен курс

- 9 шагов (0–8): от пустого файла до полной игры с вводом из консоли,
  посимвольной проверкой ответов и счётом очков.
- На каждом шаге — блок «новый код» и **файл целиком**: строки,
  добавленные на этом шаге, подсвечены зелёным.
- Каждый шаг — самостоятельная компилируемая программа
  (проверено: все 7 файлов шагов собираются разумом и искрой).
- Концепции объясняются «в момент нужды»: указатели — когда читаем
  консоль, `лог` — когда проверяем ответ, массивы — когда вопросов
  становится три.
- Проверочные вопросы с пояснениями, прогресс в localStorage.
- Песочница — редактор с живой подсветкой и шпаргалкой.

## Файлы

- `index.html` — каркас страницы;
- `style.css` — тёмная тема;
- `razum-hl.js` — собственный подсветчик синтаксиса РАЗУМА
  (ключевые слова, типы `цел.верх`, строки, числа, комментарии `#`/`;`,
  мнемоники ИСКРЫ в блоках `искра:`, устаревшие `цел8`/`бул`);
- `steps.js` — шаги курса: исходник собирается из кусочков (`CH`),
  `newIdx` помечает добавленные строки;
- `app.js` — рендер шагов, проверки, прогресс, песочница.

Финальная программа курса также лежит в корне репозитория:
`_викторина.раз` (собрана в `_викторина.exe`, проверена на вводе
`2 1 3` → «Итог: 3 из 3», код выхода = счёт).

## Проверено

- Все 7 промежуточных файлов шагов компилируются `разум` + `искра`.
- Финал запущен с ответами через pipe — счёт и код выхода корректны.
- PowerShell-особенность учтена: команды сборки даны через `cmd /c`,
  т.к. PowerShell не поддерживает `<`.
