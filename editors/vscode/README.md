# ВЕЛЕС — расширение VSCode для ИСКРА, РАЗУМ и ЯР

Подсветка синтаксиса (TextMate-грамматики) для трёх русских языков
экосистемы ВЕЛЕС:

| Язык | Файл | Назначение | Грамматика |
|------|------|------------|------------|
| ИСКРА | `.иск` | русский ассемблер x86-64 | `syntaxes/iskra.tmLanguage.json` |
| РАЗУМ | `.раз` | системный язык | `syntaxes/razum.tmLanguage.json` |
| ЯР    | `.яр`  | флагманский язык (в разработке) | `syntaxes/yar.tmLanguage.json` |

## Установка

### Вариант 1: копия каталога (простой)

Скопируйте каталог `editors/vscode` в папку расширений пользователя под
именем `veles-languages`:

```powershell
Copy-Item -Recurse "путь\к\veles\editors\vscode" "$env:USERPROFILE\.vscode\extensions\veles-languages"
```

Перезапустите VSCode.

### Вариант 2: упаковка через vsce

```powershell
cd editors\vscode
npm install -g @vscode/vsce   ; один раз, если vsce ещё нет
vsce package                  ; получится veles-languages-0.2.0.vsix
code --install-extension veles-languages-0.2.0.vsix
```

### Вариант 3: для разработки

Откройте папку `editors/vscode` в VSCode и нажмите `F5` — запустится
окно Extension Development Host с подключённым расширением.

## Что подсвечивается

### ИСКРА (`.иск`)

- **Мнемоники** (`keyword.control`): ПЕР, ДОБ, ДОБП, ВЫЧ, ВЫЧП, СРАВ, И, ИЛИ,
  ИИЛИ, НЕ, ОТР, УМН, УМНБ, ДЕЛ, ДЕЛБ, ВРЛ, ВРП, СДЛ, СДП, СДПА, УВЕЛ, УМЕН,
  ВСТЕК, ИЗСТЕКА, ВЫЗОВ, ВОЗВРАТ, ПРЫГ, АДР, ОБМЕН, ПРОВ, ЗНАКРАСШ, БЕЗРАСШ,
  ЗНАКРАСШД, НОП, СТОП, ПРЕРЫВ, СИСВЫЗОВ, ПОКИНЬ, РАСШ, РАСШД;
  все условные переходы (РАВНО, НОЛЬ, НЕРАВНО, НИЖЕ, ВЫШЕ, МЕНЬШЕ, БОЛЬШЕ,
  ПЕРЕНОС, ЗНАК, ЧЁТ/ЧЕТ и остальные варианты) и `УСТ<условие>` (setcc).
- **Директивы и регистры** (`support.constant`): СЕКЦИЯ, ИМПОРТ, ВХОД,
  ВЫРОВНЯТЬ, РЕЗЕРВ; имена секций после `СЕКЦИЯ` — `entity.name.section`,
  имя DLL после `ИМПОРТ` — `entity.name.namespace`; русские регистры
  АКК, СЧТ, ДАН, БАЗ, УКС, УКК, ИСТ, ПРМ, Р8–Р15 с суффиксами М/П/Б
  (АККМ, СЧТБ, Р8П…), а также латинские имена rax–dil и r8–r15 с
  суффиксами d/w/b.
- **Псевдоинструкции** (`keyword.other.pseudo`): ВХОДКАДРА, ВЫХОДКАДРА —
  пролог/эпилог кадра, разворачиваются парсером в несколько инструкций.
- **Прагма цели**: первая строка `;цель windows|linux|macos` — слово
  `цель` подсвечивается директивой, имя цели — `constant.language`;
  сама строка остаётся комментарием (лексер видит её как `;`-комментарий).
- **Размеры данных/операндов** (`storage.type`): БАЙТ, СЛОВО, ДВСЛОВО, КВАД.
- **Метки и константы**: `метка:` — `entity.name.function`; метки
  генератора `м_<функция>_<контекст>_<номер>` — `entity.name.tag`
  (отдельный цвет от пользовательских меток); `имя РАВНО выражение` —
  `constant.other`; ЗДЕСЬ и `$` — `constant.language`.
- **Числа**: десятичные, `0x`, `0b`, `0o`, разделитель `_`.
- **Строки**: двойные и одинарные кавычки, экраны `\n \t \r \0`.
- **Комментарии**: только `;` (лексер ИСКРЫ `#` не принимает — это ошибка
  ассемблера, грамматика его не подсвечивает).

Регистр букв в мнемониках и именах регистров не важен — как в самом
ассемблере (`пер`, `Пер`, `ПЕР` эквивалентны).

### РАЗУМ (`.раз`)

- **Управление** (`keyword.control`): если, а если, иначе, пока, вечно, для,
  выбор, верни, хватит, следующий, отложи, искра.
- **Объявления** (`keyword`): взять, внеш, функ, запись, переч, тип,
  конст, введи; имена после `функ`/`запись`/`переч`/`тип`/`конст`
  подсвечиваются как `entity.name.function` / `entity.name.type` /
  `constant.other`.
- **Слова-операторы** (`keyword.operator`): и, или, не, не в, в, как,
  новый, размер; знаки `..`, `..=`, `<<`, `>>`, `+=` и т.д.
  Устаревшее `:=` подсвечивается как `invalid.deprecated` — канонические
  объявления: `имя тип = выражение` и `введи имя = выражение` (вывод типа).
- **Типы** (`storage.type`): семейства `цел`, `нат`, `вещ` с уровнями
  `.старт`/`.шаг`/`.рост`/`.верх`/`.пик` (точечная форма, уровень
  подсвечен как часть типа), а также `лог`, `сим`, `стр`, `знак`.
  Плоские алиасы переходного периода (`цел8`…`цел64`, `без8`…`без64`,
  `бул`, `д32`, `д64`) помечаются `invalid.deprecated`.
- **Пути модулей** (`entity.name.namespace`): `взять сист.файл`,
  цепочки вида `мат.цел.нод` — сегменты до последней точки как
  пространство имён, вызов на конце цепочки — `entity.name.function`;
  одиночное `объект.поле` — объект + `variable.other.property`.
- **Предикаты** (`entity.name.function.predicate`): вызовы `это_*`
  и `*_это_*` (например `это_цифра`, `цел_это_простое`) — отдельный
  подскоуп, булевы проверки читаются как проверки.
- **Вызовы функций** (`entity.name.function`): имя перед `(`.
- **Литералы** (`constant.language`): да, нет, пусто.
- **Встроенные функции** (`support.function.builtin`): выдели, освободи.
- **Строки**: `"..."` с экранами `\n \r \t \0 \\ \" \' \xNN`;
  символьные литералы `'x'`.
- **Числа**: десятичные, `0x`, `0b`, `0o`, разделитель `_`.
- **Комментарии**: `#` и `;` до конца строки (оба принимает лексер;
  для переключения комментария по Ctrl+/ используется `#`).
- **Вложенная ИСКРА**: блок `искра:` подсвечивается полной грамматикой
  ИСКРЫ (`source.iskra`) — конец блока определяется по отступу: блок
  продолжается, пока строки отступлены глубже слова `искра:`.

### ЯР (`.яр`) — грамматика предварительная

Синтаксис Яра описан черновиком `docs/03-яр.md` и может меняться;
грамматика составлена по спецификации v0.1-черновик:

- **Управление**: если, а если, иначе, выбор, для, вечно, пока,
  раз/раза/разы, хватит, следующий, дай, попробуй, не вышло, всё равно;
  брось (из «открытых вопросов» спеки).
- **Объявления**: взять, суть, из, умеет; имена после `умеет` и `суть`
  (включая `суть Имя из Родитель`) — как функции и типы.
- **Операторы**: и, или, не, не в, не пусто, как, в; знаки `..`, `..=`,
  `//`, `==`, `!=`, `+=` и т.д.
- **Литералы**: да, нет, пусто; специальные имена оно и тут —
  `variable.language`.
- **Строки** `"..."` с интерполяцией `{выражение}` — внутри фигурных
  скобок подсвечиваются ключевые слова, числа и вложенные строки.
- **Числа**: десятичные, вещественные, `0x`.
- **Комментарии**: `#`.

## Сниппеты

| Префикс | Язык | Шаблон |
|---------|------|--------|
| `функ`, `функ метод`, `главная` | РАЗУМ | объявления функций |
| `если`, `если-иначе`, `а если`, `выбор` | РАЗУМ | ветвления |
| `пока`, `вечно`, `для`, `отложи` | РАЗУМ | циклы и отложенный вызов |
| `взять`, `взять путь`, `внеш`, `объяв`, `введи`, `запись`, `переч`, `конст` | РАЗУМ | импорты и объявления |
| `искра` | РАЗУМ | вложенный блок `искра:` |
| `программа`, `;цель`, `секция`, `вход` | ИСКРА | каркас программы, прагма цели |
| `метка`, `равно`, `входкадра`, `выходкадра` | ИСКРА | метки, константы, кадр стека |
| `байт`, `квад`, `строка` | ИСКРА | данные |
| `выход linux`, `выход macos`, `вывод linux`, `вызов` | ИСКРА | системные вызовы |

## Структура

```
editors/vscode/
├── package.json                       — манифест расширения
├── language-configuration.json        — скобки/комментарии (РАЗУМ, ЯР: "#")

│   ├── iskra.tmLanguage.json          — source.iskra
│   ├── razum.tmLanguage.json          — source.razum

├── snippets/
│   ├── iskra.json                     — шаблоны секций, входа, меток
│   └── razum.json                     — шаблоны функ/если/пока/искра: и др.
└── README.md
```

## Источники лексики

Грамматики собраны по реальному коду, а не по памяти:

- ИСКРА: `иск/рег.раз` (регистры), `иск/кодер.раз` (мнемоники),
  `иск/парсер.раз` (директивы, РАВНО, ЗДЕСЬ), `иск/лексер.раз`
  (комментарий `;`, числа, строки).
- РАЗУМ: `raz/лексер.раз` (комментарии `#`/`;`, операторы, экраны),
  `raz/парсер.раз` (ключевые слова, точечные типы), `биб/узлы.раз` (типы),
  `raz/ген.раз` (выдели/освободи, метки `м_*`).
- ЯР: `docs/03-яр.md` (черновик спецификации).
