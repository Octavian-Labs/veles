# ИЩИ — поиск текста по файлам

Нативная консольная утилита на РАЗУМЕ для поиска UTF-8-текста. Не использует
сторонние зависимости.

## Возможности v0.1

- поиск по одному или нескольким путям;
- рекурсивный обход каталогов Windows;
- номера строк и Unicode-столбцов;
- поиск без учёта регистра для ASCII и кириллицы UTF-8;
- фильтр расширения;
- режим вывода только имён файлов;
- пропуск двоичных файлов по умолчанию;
- пути с пробелами и кавычками;
- итоговые счётчики;
- стабильные коды выхода.

Linux и macOS в v0.1 компилируются и поддерживают явно перечисленные файлы.
Рекурсивное перечисление каталогов через `getdents64`/`getdirentries64` —
следующий этап платформенного слоя.

## Сборка Windows

Из каталога `ищи/`:

```powershell
cmd /c "..\raz\разум.exe < ищи.раз > ищи.иск"
cmd /c "..\искра.exe < ищи.иск > ищи.exe"
```

## Примеры

```powershell
# Рекурсивный поиск
.\ищи.exe "точка_пост" ..\след

# Кириллица без учёта регистра
.\ищи.exe -н "искомый" проверка

# Только исходники РАЗУМА, только имена файлов
.\ищи.exe --расш .раз -л "точка" ..\след

# Не входить во вложенные каталоги
.\ищи.exe --без-рекурсии "образец" каталог

# Путь с пробелом
.\ищи.exe "пример" "проверка\вложенный каталог\второй.раз"
```

## Параметры

| Параметр | Назначение |
|---|---|
| `-н`, `--без-регистра` | Не учитывать регистр ASCII и кириллицы |
| `-л`, `--только-имена` | Вывести каждый найденный файл один раз |
| `--без-рекурсии` | Не обходить вложенные каталоги |
| `--расш <.раз>` | Ограничить поиск расширением |
| `--двоичные` | Искать и в файлах с нулевыми байтами |
| `--итог` | Вывести число файлов, совпадений и ошибок |
| `-п`, `--помощь` | Показать справку |

Если путь не указан, используется текущий каталог. Параметр `--` завершает
разбор параметров и позволяет искать образец, начинающийся с дефиса.

## Формат вывода

```text
путь:строка:столбец: содержимое строки
```

Строки считаются с 1. Столбец считается по кодовым точкам UTF-8, а не по
байтам. Поиск остаётся байтовым, поэтому совпадение всегда начинается на
реальной границе UTF-8 для корректных текстовых данных.

## Коды выхода

| Код | Значение |
|---:|---|
| 0 | Найдено хотя бы одно совпадение |
| 1 | Совпадений нет |
| 2 | Ошибка параметров, пути или чтения |

## Устройство

- `ищи.раз` — разбор аргументов, поиск, форматирование и коды выхода;
- `каталог.windows.раз` — `FindFirstFileW`/`FindNextFileW`, UTF-16 ↔ UTF-8;
- `каталог.linux.раз`, `каталог.macos.раз` — текущий файловый слой прямых путей;
- `проверка/` — воспроизводимые UTF-8-данные, включая путь с пробелом.

Windows-обход не следует по точкам повторного разбора (`reparse point`), чтобы
не зациклиться на соединениях каталогов.
