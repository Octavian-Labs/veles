# РАЗУМ — спецификация системного языка (EBNF + семантика)

> Версия 0.1-черновик, 2026-09-19. РАЗУМ — средний уровень экосистемы ВЕЛЕС:
> ИСКРА (ассемблер) → **РАЗУМ** (системы) → ЯР (флагман).
>
> Назначение: ядра ОС, драйверы, рантаймы, компиляторы — включая будущий
> компилятор РАЗУМА (самораскрутка) и рантайм Яра.

## 0. Принципы дизайна

- **Статическая типизация, вывод типов где очевидно** (`х := 5`).
- **Никакого GC.** Ручная память: `новый`/`освободи`, адреса и размеры явные.
- **Ноль скрытых действий.** Нет неявных аллокаций, копирований, исключений.
- **Компиляция в ИСКРУ.** Компилятор генерирует текст `.иск`, ассемблер
  производит PE64/ELF64 — переносимость достаётся бесплатно.
- **Читается по-русски** там, где это не вредит точности (та же школа,
  что и у Яра: `если`, `а если`, `пока`, `х в 0..10`, `х как без32`).

## 1. Типы

```ebnf
тип   := простой | "*" тип | тип "[" [ число ] "]" | "функ" "(" [ типы ] ")" [ тип ]

простой :=
    "цел8"  "цел16"  "цел32"  "цел64"      ; знаковые
  | "без8"  "без16"  "без32"  "без64"      ; беззнаковые
  | "бул"                                ; да / нет
  | "сим"                                ; = без8
  | "д32"  "д64"                         ; IEEE-754 (этап 2, нужен SSE)
  | "пусто"                              ; void: нет значения
  | "стр"                                ; { данные *без8, длина без64 }
  | имя                                  ; записи, перечисления, синонимы
```

| Конструкция | Смысл |
|-------------|-------|
| `*Т` | указатель на Т (`*пусто` ≈ void*) |
| `Т[N]` | массив фиксированной длины |
| `[]Т` | срез: `{ данные *Т, длина без64 }` |
| `функ(цел64) цел32` | тип функции (для указателей на функции) |

## 2. Переменные и константы

```ebnf
объявление := имя [ имя_типа ] ":=" выражение          ; вывод типа
            | имя тип "=" выражение                    ; явный тип
            | "конст" имя "=" выражение                ; время компиляции
            | "тип" имя "=" тип                        ; синоним типа
```

```go
счёт := 0                    ; цел64 по умолчанию
буфер: без8[256]             ; аналогично: буфер без8[256] — решить ниже
размер без64 = 4096
конст ШИРИНА = 10
тип хендл = без64            ; свой HWND
```

## 3. Функции

```ebnf
функция := "функ" имя "(" [ параметры ] ")" [ тип ] блок
         | "функ" "(" приёмник ")" имя "(" [ параметры ] ")" [ тип ] блок  ; метод
параметры := имя { "," имя } тип { "," имя { "," имя } тип }
приёмник  := имя тип
```

Типы идут **после** имён, группы с одним типом схлопываются:

```go
функ площадь(ш, в цел64) цел64:
    верни ш * в

функ главная() цел32:
    верни 0

запись Точка: х, у цел64
функ (т Точка) квадрат_нормы() цел64:
    верни т.х * т.х + т.у * т.у
```

## 4. Управление

```ebnf
если_оп    := "если" выр блок { "а" "если" выр блок } [ "иначе" блок ]
выбор      := "выбор" выр блок_вариантов      ; образцы: литералы и a..b
пока_оп    := "пока" выр блок
для        := "для" имя "в" выр блок          ; диапазон или массив/срез
           | "для" имя "," имя "в" выр блок   ; (индекс, элемент)
вечно      := "вечно" блок
управление := "верни" [ выр ] | "хватит" | "следующий" | "отложи" выр
```

- `отложи выр` — defer: выполнится при выходе из функции (LIFO).
- Постфиксные модификаторы (как в Яре): `действие если усл`, `действие пока усл`.

## 5. Указатели и память

```ebnf
адрес      := "&" цель                      ; взять адрес
разымен    := "*" выражение                 ; разыменовать
```

```go
новый(Т)            ; выделить sizeof(Т), вернуть *Т   (stdlib: куча.взять)
освободи(указ)      ; вернуть память
размер(Т/выр)       ; sizeof — время компиляции
смести(указ, тип)   ; reinterpret_cast → или короче: указ как *без8
```

Приведение типов — постфиксное `как`: `х как без32`, `указ как *цел64`.
Это единственный способ смены типа — никаких неявных конверсий.

## 6. Внешние функции и встроенная ИСКРА

```ebnf
внеш      := "внеш" строка "функ" имя "(" [ параметры ] ")" [ тип ]
искра     := "искра" ":" НС ОТСТУП { строка_искры } СНЯТИЕ
```

```go
внеш "kernel32" функ ExitProcess(код без32)

функ выход(код без32):
    искра:
        ПЕР СЧТМ, код        ; локали и параметры видны по имени
        ВЫЗОВ ExitProcess
```

Блок `искра:` вставляет текст ИСКРЫ напрямую в вывод компилятора —
низкоуровневый люк для syscall, портов ввода-вывода, привилегированных
инструкций. Незаменим при написании ОС.

Имена локальных переменных и параметров внутри блока подставляются
компилятором как адреса `[УКК±смещение]` — ассемблерные строки остаются
сырым кодом, но могут читать и писать переменные РАЗУМА.

## 7. Модули

```ebnf
взять := "взять" имя { "," имя }     ; модуль = файл .раз
```

Без заголовочных файлов: всё объявленное с большой буквы — экспортируется.
Модуль ищется рядом с импортирующим файлом (`имя.раз`), затем в `lib/`
рядом и уровнем выше. Каждый файл подключается один раз; циклические
импорты отсекаются.

Платформенные реализации: `взять консоль` сначала ищет
`консоль.<цель>.раз` (`консоль.windows.раз`, `консоль.linux.раз`), затем
нейтральный `консоль.раз`.

Стандартная библиотека — `lib/`:

```go
взять основа          ; зонтик: память + стр + консоль
взять стр             ; только строки

печать("текст")       ; stdout
печатьстр("строка")   ; + перевод строки
печатьцел(6 * 7)      ; Ответ: 42
стр_склей(а, б)       ; новая строка в куче
стр_равны(а, б)       ; бул
стр_срез(с, а, б)     ; подстрока без копирования
цел_в_стр(ч)          ; десятичное представление
скопируй(куда, откуда, n); заполни(указ, б, n); равна_память(а, б, n)
выдели(n)             ; n байт из кучи (встроенная, как новый)
```

## 8. Грамматика (выражения)

Приоритеты совпадают с Яром, плюс:

```ebnf
выражение  := или_выр [ "как" тип ]*          ; приведение — самый слабый постфикс
атом       := число | строка | "да" | "нет" | "пусто"
            | имя | "(" выр ")" | литерал | "новый" "(" тип ")"
            | "размер" "(" тип ")"
литерал    := тип "{" [ элем {"," элем} ] "}"     ; записи и массивы
элем       := [ имя ":" ] выражение
срез_оп    := выр "[" выр (".." | "..=") выр "]"  ; об[a..b] -> []Т
```

```go
т Точка = Точка{х: 3, у: 4}          ; именованные поля
т2 = Точка{3, 4}                     ; позиционные — по порядку полей
arr без8[5] = без8[5]{10, 20, 30, 40, 50}
ср := arr[1..4]                      ; []без8: {данные: arr+1, длина: 3}
ф функ(цел64) цел64 = удвоить        ; указатель на функцию
н = ф(21)                            ; косвенный вызов
```

## 9. Пример — «Привет, мир!» на РАЗУМЕ (Windows)

```go
внеш "kernel32" функ GetStdHandle(деск без32) без64
внеш "kernel32" функ WriteFile(хендл без64, буф *без8,
                               колво без32, записано *без32, овер *пусто) цел32
внеш "kernel32" функ ExitProcess(код без32)

функ главная():
    сооб := "Привет, мир!\r\n"          ; стр: {данные, длина}
    записано без32 = 0
    х := GetStdHandle(0xFFFFFFF5)
    WriteFile(х, сооб.данные, сооб.длина как без32, &записано, пусто)
    ExitProcess(0)
```

И то же через `искра:` без единого внешнего вызова — уже сегодня.

## 10. Стратегия реализации

```
разум.py:  исходник .раз → лексер → AST → проверка типов → генератор
                │
                ▼  текст ИСКРЫ (.иск)
           iskra.assemble() ──► PE64 / ELF64
```

- **Кодген MVP — стековый**: каждое выражение через ВСТЕК/ИЗСТЕКА и АКК/СЧТ.
  Медленно, но верифицируемо; оптимизация регистров — отдельная веха.
- **ABI:** Windows — rcx/rdx/r8/r9 + теневое пространство; Linux — SysV
  (rdi/rsi/rdx/rcx/r8/r9) + СИСВЫЗОВ. Эмиттер уже умеет обе цели.
- **Самораскрутка:** компилятор сначала на Python; когда РАЗУМ стабилен —
  переписывается на РАЗУМЕ и компилирует сам себя через ИСКРУ.

## 11. Реализовано (v0.2)

- Методы `функ (т Точка) имя(...)` и `функ (т *Точка) имя(...)`; вызов
  `об.имя(...)`. Приёмник передаётся первым аргументом как `*запись`
  (приёмник по значению пока получает указатель — семантика копии — этап 3).
- Косвенные вызовы: переменные и параметры типа `функ(...)`, вызов через
  `ВЫЗОВ Р11` (ИСКРА умеет `ВЫЗОВ регистр`/`ВЫЗОВ [память]`).
- Литералы `Тип{...}` для записей (именованные и позиционные поля) и
  массивов; незаполненные поля обнуляются. Проверка типов элементов и
  диапазона числовых литералов.
- Срез `об[a..b]` / `об[a..=b]` — для массивов, указателей, срезов и `стр`;
  результат — пара `{данные, длина}`.
- `взять модуль` — загрузка `.раз`-файлов (рядом с источником и в `lib/`),
  защита от циклов. Фундамент stdlib «основа».
- `искра:` видит локали и параметры по имени (подстановка `[УКК±off]`).

## 12. Открытые вопросы

- `имя тип = знач` против `имя: тип = знач` — синтаксис объявлений с типом.
- Ошибки: коды возврата vs `результат` тип-сумма (`ок(х)/сбой(е)`)? 
- Пакетная система и стандартная библиотека (`основа`: память, стр, файлы).
- Срезы vs массивы — границы проверять или нет (режим `быстро`/`надёжно`)?
- Дробные (д32/д64) — нужен SSE в кодировщике ИСКРЫ.
