# ЯР — спецификация языка (грамматика EBNF)

> Версия 0.1-черновик, состояние сверено 2026-09-21. ЯР — будущий язык
> высокого уровня после ИСКРЫ и РАЗУМА. Реализация ещё не начата; этот
> документ фиксирует направление, но не описывает работающий компилятор.
>
> Принцип дизайна: **код читается вслух как русская речь**.
> Динамическая типизация, блоки по отступам, интерполяция строк,
> постфиксные модификаторы.

## 0. Решения по двусмысленностям (приняты при составлении грамматики)

| Вопрос | Решение |
|--------|---------|
| `пусто` — предикат или значение? | **Обе роли, разные позиции.** Как атом — значение («ничего»). После операнда сравнения — проверка: `х пусто`, `х не пусто`. Парсер различает по позиции. |
| `оно` — результат чего? | Результат **последнего оператора-выражения** в текущем блоке. Не пересчитывается внутри вложенных выражений. Предупреждение в документации: в длинных функциях лучше имя. |
| Именованные аргументы: `:` или `=`? | **Везде `=`**: и в вызовах (`су=1`), и в конструкторах (`Фигура(вид=3)`). Единообразие важнее. |
| Диапазоны `a..b` — границы? | `a..b` — **полуоткрытый** [a, b): `0..ШИРИНА` = 0..9. `a..=b` — **включая** b: `19..=0` = 19..0. Шаг ±1 по направлению. |
| `суть` — поля без значений? | Поле без `= дефолт` — обязательный параметр конструктора. С `=` — необязательный. |
| `5 раз` — склонение? | `раз`, `раза`, `разы` — все три формы допустимы (компилятору всё равно, человеку — по слуху). |

## 1. Лексика

```ebnf
комментарий  := "#" { любой_символ }
имя          := ( буква | "_" ) { буква | цифра | "_" }   ; кириллица и латиница
число        := целое | вещественное | "0x" цифра16 { цифра16 }
строка       := '"' { литерал_сим | "{" выражение "}" } '"'  ; интерполяция
```

**Ключевые слова** (~30, регистр не важен для слов-операторов):

```
взять  суть  из  умеет  если  а если  иначе  выбор  как
для  в  вечно  пока  раз/раза/разы  хватит  следующий  дай
попробуй  не вышло  всё равно  да  нет  пусто  не  и  или  оно  тут
```

## 2. Структура программы

```ebnf
программа    := { оператор }
блок         := ":" простой_оператор                       ; однострочный
              | ":" НС ОТСТУП оператор { оператор } СНЯТИЕ ; блок отступом
```

`НС` — новая строка, `ОТСТУП`/`СНЯТИЕ` — изменение уровня отступа.

## 3. Операторы

```ebnf
оператор     := простой [ модификатор ] | составной

простой      := присваивание
              | вызов_или_выражение
              | "дай" [ выражение ]        ; ранний выход из функции
              | "хватит"                   ; break
              | "следующий"                ; continue

модификатор  := "если" выражение           ; «сделай X если Y»
              | "пока" выражение           ; «делай X пока Y»

присваивание := цель ( "=" | "+=" | "-=" | "*=" | "/=" | "%=" ) выражение
цель         := имя | постфикс_цель        ; имя, объект.поле, объект[индекс]
```

**Неявный возврат:** последнее выражение тела `умеет` — возвращаемое
значение. `дай` — для раннего выхода (без аргумента возвращает `пусто`).

## 4. Составные операторы

```ebnf
если_оп      := "если" выражение блок
                { "а" "если" выражение блок }
                [ "иначе" блок ]

выбор        := "выбор" выражение блок_вариантов
вариант      := образец блок
образец      := литерал | литерал ".." литерал | "иначе"

для          := "для" имя "в" выражение
                { "," имя "в" выражение } блок
пока_оп      := "пока" выражение блок
вечно        := "вечно" блок
разы         := выражение ( "раз" | "раза" | "разы" ) блок
```

## 5. Объявления

```ebnf
умеет        := "умеет" имя "(" [ параметры ] ")" блок
параметры    := параметр { "," параметр }
параметр     := имя [ "=" выражение ]       ; умолчание

суть         := "суть" имя [ "из" имя ] ":" строка_полей
              | "суть" имя [ "из" имя ] блок_сути
строка_полей := имя [ "=" выражение ] { "," имя [ "=" выражение ] }
блок_сути    := блок                        ; внутри: поля и «умеет»

взять        := "взять" имя { "," имя }

попробуй     := "попробуй" блок
                "не" "вышло" [ "как" имя ] блок
                [ "всё" "равно" блок ]
```

В методах `сути` первым скрытым параметром выступает `тут` (аналог self):
`тут.х` — «здесь мой икс».

## 6. Выражения (приоритеты, от слабого к сильному)

```ebnf
выражение    := тернар
тернар       := или_выр [ "если" выражение "иначе" тернар ]
                                ; «"#" если занято иначе " "»
или_выр      := и_выр { "или" и_выр }
и_выр        := не_выр { "и" не_выр }
не_выр       := "не" не_выр | сравнение
сравнение    := сумма [ сравн_оп сумма
                      | "пусто"                ; предикат «это пусто»
                      | "не" "пусто" ]         ; «это не пусто»
сравн_оп     := "==" | "!=" | "<" | "<=" | ">" | ">="
              | "в" | "не" "в"                 ; «х в 0..10», «х не в список»

сумма        := [ сумма ( ".." | "..=" ) ] произв   ; диапазоны
              | сумма ( "+" | "-" ) произв
              | произв
произв       := произв ( "*" | "/" | "//" | "%" ) унарн | унарн
унарн        := ( "-" | "не" ) унарн | постфикс
постфикс     := атом { "." имя
                     | "(" [ аргументы ] ")"
                     | "[" выражение "]" }
аргументы    := аргумент { "," аргумент }
аргумент     := [ имя "=" ] выражение

атом         := число | строка | "да" | "нет" | "пусто"
              | "оно" | "тут" | имя
              | "(" выражение ")"
              | список | словарь | генсписок
список       := "[" [ выражение { "," выражение } ] "]"
словарь      := "{" [ имя_или_стр ":" выражение { "," ... } ] "}"
генсписок    := "[" выражение "для" имя "в" выражение
                [ "если" выражение ] "]"
```

## 7. Истинность

Ложь — это: `нет`, `пусто`, `0`, `0.0`, `""`, `[]`, `{}`.
Всё остальное — правда. Поэтому `если линии` = «если линий не ноль».

## 8. Пример (Тетрис, исправленный под грамматику)

```text
взять консоль, рандом, время

суть Фигура: вид, поворот = 0, х = 3, у = 0

умеет столкновение(поле, фиг, сх = 0, су = 0, поворот = 0):
    форма = ФОРМЫ[фиг.вид][(фиг.поворот + поворот) % 4]
    для ряд в 0..4, кол в 0..4:
        если форма[ряд][кол]:
            нх = фиг.х + кол + сх
            ну = фиг.у + ряд + су
            если нх не в 0..ШИРИНА или ну >= ВЫСОТА:
                дай да
            если ну >= 0 и поле[ну][нх]:
                дай да
    нет                              ; неявный возврат

умеет почистить(поле):
    убрано = 0
    для ряд в ВЫСОТА-1..=0:          ; снизу вверх, включая ноль
        если 0 не в поле[ряд]:
            поле.выкинуть(ряд)
            поле.сверху([0] * ШИРИНА)
            убрано += 1
    убрано

# внутри игрового цикла:
фиг.х -= 1 если не столкновение(поле, фиг, сх = -1)
фиг.у += 1 пока не столкновение(поле, фиг, су = 1)

выбор клавиша:
    "влево":  фиг.х -= 1 если не столкновение(поле, фиг, сх = -1)
    "выход":  хватит
    иначе:    следующий
```

## 9. Открытые вопросы (следующие итерации)

- Модель ошибок: `попробуй / не вышло / всё равно` — типы ошибок, `брось`.
- `оно`: ограничить область (строка? блок? REPL?) — нужен опыт использования.
- Синонимы ключевых слов (`хватит`/`всё`/`стоп`) — свобода vs единообразие.
- Статическая типизация-опция для «системного режима» Яра.
- Реализация: компилятор ЯР→ИСКРА или ЯР→байткод + рантайм на РАЗУМЕ.
