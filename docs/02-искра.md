# Спецификация ассемблера ИСКРА (x86-64)

> Версия 0.1, 2026-09-19. Синтаксис по мотивам Intel, все мнемоники — русские.
> ИСКРА — первый уровень экосистемы ВЕЛЕС: голый процессор, настоящий машинный код.

## Общий вид строки

```asm
метка:  МНЕМОНИКА операнд1, операнд2    ; комментарий
имя     РАВНО выражение                  ; константа
```

Регистр букв в мнемониках и именах регистров не важен.
Имена меток и констант — регистрозависимы.

## Регистры

| 64 бита | 32 бита | 16 бит | 8 бит | Назначение |
|---------|---------|--------|-------|------------|
| АКК (rax)  | АККМ (eax)  | АККП (ax)  | АККБ (al)  | аккумулятор |
| СЧТ (rcx)  | СЧТМ (ecx)  | СЧТП (cx)  | СЧТБ (cl)  | счётчик |
| ДАН (rdx)  | ДАНМ (edx)  | ДАНП (dx)  | ДАНБ (dl)  | данные |
| БАЗ (rbx)  | БАЗМ (ebx)  | БАЗП (bx)  | БАЗБ (bl)  | база |
| УКС (rsp)  | УКСМ (esp)  | УКСП (sp)  | УКСБ (spl) | указатель стека |
| УКК (rbp)  | УККМ (ebp)  | УККП (bp)  | УККБ (bpl) | указатель кадра |
| ИСТ (rsi)  | ИСТМ (esi)  | ИСТП (si)  | ИСТБ (sil) | источник |
| ПРМ (rdi)  | ПРММ (edi)  | ПРМП (di)  | ПРМБ (dil) | приёмник |
| Р8..Р15    | Р8М..Р15М   | Р8П..Р15П  | Р8Б..Р15Б  | дополнительные |

Допустимы и английские имена (rax, eax, r8d и т.д.).

## Директивы

| Директива | Назначение |
|-----------|-----------|
| `СЕКЦИЯ код` / `СЕКЦИЯ данные` | переключение секции (.text/.data) |
| `БАЙТ v, "стр", ...` | байты данных (строки — UTF-8) |
| `СЛОВО / ДВСЛОВО / КВАД v,...` | данные по 2/4/8 байт |
| `РЕЗЕРВ n` | зарезервировать n нулевых байт |
| `ВЫРОВНЯТЬ n` | выравнивание (степень двойки) |
| `ИМПОРТ "dll" Ф1, Ф2` | импорт функций Windows DLL |
| `ВХОД метка` | точка входа (по умолчанию `старт`) |
| `имя РАВНО выр` | константа; `$`/`ЗДЕСЬ` — текущий адрес |

## Адресация

```asm
ПЕР АКК, [БАЗ]              ; по адресу в регистре
ПЕР АКК, [БАЗ+16]           ; база + смещение
ПЕР АКК, [БАЗ+ИСТ*4+16]     ; база + индекс*масштаб + смещение
АДР ДАН, [сообщение]        ; адрес метки (RIP-относительно)
ПЕР КВАД [УКС+32], 0        ; явный размер: БАЙТ/СЛОВО/ДВСЛОВО/КВАД
```

Ограничение MVP: метка в `[]` допустима только как единственное слагаемое
(RIP-относительная адресация — переносимо и без таблицы релокаций).

## Вызовы WinAPI (Windows)

```asm
ИМПОРТ "kernel32.dll" GetStdHandle, WriteFile, ExitProcess
...
ВЫЗОВ GetStdHandle          ; call [rip + IAT] — ячейка заполняется загрузчиком
```

## Системные вызовы (Linux)

```asm
ПЕР АККМ, 1      ; sys_write      ПЕР АККМ, 60     ; sys_exit
ПЕР ПРММ, 1      ; fd=stdout      ИИЛИ ПРММ, ПРММ  ; код 0
АДР ИСТ, [сообщение]
ПЕР ДАНМ, длина
СИСВЫЗОВ                        СИСВЫЗОВ
```

## CLI

```powershell
# Windows: искра.exe читает ИСКРУ со stdin, пишет PE64 в stdout
.\искра.exe < файл.иск > prog.exe

# Linux: то же самое; цель задаёт прагма «;цель linux» в первой строке
./искра < файл.иск > prog
```
