# Архитектура и роадмап экосистемы ВЕЛЕС

> Дата создания: 2026-09-19

## Цель

Собственная полностью русская система программирования «с нуля» —
три языка, образующие линию восхождения по уровням абстракции:

```
ИСКРА (ассемблер)  →  РАЗУМ (системный, C-уровень)  →  ЯР (флагман, верхний уровень)
  голый процессор       ядра, драйверы, рантаймы       ОС, ИИ-системы, нейро-платформы
```

Конечная цель — платформа, на которой пишут операционные системы,
ИИ-системы и операционные системы на базе нейросетей.

## Принятые решения

- **Целевой процессор:** реальный x86-64 (AMD64). Никаких виртуальных машин —
  ИСКРА генерирует настоящие байты машинного кода.
- **Первый ассемблер написан на Python.** Это инструмент раскрутки:
  важно не «на чём написан», а что он производит — реальный низкоуровневый
  код с русскими мнемониками.
- **Переносимость** достигается целями сборки: один исходник на ИСКРЕ
  ассемблируется под Windows (PE64 + WinAPI) и Linux (ELF64 + syscall).
  Позже: macOS (Mach-O) и ARM64.
- **Честная оговорка:** один и тот же бинарник не может исполняться на всех
  ОС — разные форматы файлов и интерфейсы ядра. Переносимость — на уровне
  исходного текста и единого ассемблера.

## Этапы (роадмап)

| Этап | Содержание | Статус |
|------|-----------|--------|
| 1 | Ассемблер ИСКРА: лексер, парсер, кодировщик x86-64, эмиттер PE64 | **готово** |
| 2 | Эмиттер ELF64 (Linux, syscall) | **готово** |
| 3 | Язык РАЗУМ: статические типы, ручная память, компилятор → текст ИСКРЫ, stdlib (файлы, ввод, список, буфер) | **готово** |
| 4 | Самораскрутка: РАЗУМ и ИСКРА переписаны на РАЗУМЕ (`raz/`, `иск/`), байтовый паритет с Python-эталоном, цепочка воспроизводит себя | **готово** |
| 5 | Оптимизации: пипхол-проход над текстом ИСКРЫ (`raz/опт.раз`, зеркало в `src/razum/gen.py`) | **готово (−22% кода, ~−20% времени)** |
| 6 | Единый CLI и уровни оптимизации `-O0/-O1` | следующий |
| 7 | Константная свёртка, затем локальное хранение переменных в регистрах | план |
| 8 | Публичный вертикальный срез: установка, единая команда сборки, 10–15 примеров, benchmark-таблица, список ограничений | план |
| 9 | Язык ЯР: динамический флагман (спека: docs/03-яр.md) | спека готова |
| 10 | Бэкенды: macOS (Mach-O), ARM64 | план |

### Ближайшие шаги (этапы 6–8)

- **`-O0`** — сборка без пипхола, для отладки компилятора и точных тестов;
  `-O1` — текущий пипхол (по умолчанию).
- **Константная свёртка** — вычисление `число op число` на этапе генерации.
- **Регистры для локалей** — самый жирный выигрыш: `д`/`n` из бенчмарка
  сейчас живут в `[УКК-8]`/`[УКК-16]`; перенос в `ИСТ`/`ПРМ` даст ещё ~3–5×.
- **Benchmark-набор**: простые (есть), копирование памяти, сравнение строк,
  вызов в цикле — с таблицей «без оптимизации / -O1».
- **Сознательно не делаем сейчас**: SSA/IR-оптимизатор (оверхед на стековом
  кодогене), сравнения с C/Rust (рано), кросс-сборку в CI.

## Известные ограничения

- РАЗУМ без структур-по-значению в сигнатурах, без плавающей точки.
- Память только ручная (`выдели`/`освободи`), проверок границ нет.
- Только x86-64: Windows (PE64 + WinAPI) и Linux (ELF64 + syscall).
- Оптимизатор — локальный (пипхол), без межфункционального анализа.

## Структура репозитория

```
veles/
  src/iskra/          # ассемблер ИСКРА (Python-эталон)
  src/razum/          # компилятор РАЗУМ (Python-эталон, с пипхолом)
  raz/                # компилятор РАЗУМ на РАЗУМЕ (самохост)
    опт.раз           # пипхол-оптимизатор
  иск/                # ассемблер ИСКРА на РАЗУМЕ (самохост)
  lib/                # стандартная библиотека на РАЗУМЕ
  examples/           # примеры .раз и .иск + бенчмарки
  tests/              # pytest (87 тестов: е2е, паритет, регрессия)
  docs/               # документация
  run_checks.ps1      # автопроверки
  .github/workflows/ci.yml
```

## Git-процесс

- `main` — стабильная версия, `develop` — рабочая, `feature/*` — функции.
- Каждое изменение — отдельной веткой от `develop`, слияние после проверок.
